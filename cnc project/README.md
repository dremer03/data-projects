# Аналитика производственных данных
🧩 Проект представляет собой исследований данных со станка ЧПУ. Перед началом проекта мы настроили сбор данных с помощью парсера на Python,который собирал данные и обрабатывал их каждые 10 минут, после чего данные загружались в базу данных. Далее эти данные скачивались в csv формате и уже анализировались.

🗂 В директории проекта вы сможет найти данные, которые мы исследовали!

### Перед нами были поставлены следующие задачи
- Посчитайте, какой статус первого канала в ЧПУ был большее количество времени?
- Какая программа была запущена дольше всего? 
- Посчитайте какой режим канала ЧПУ работал дольше по времени?
- Как долго стенды ЧПУ были online и offline?
- Определите ошибку, которая возникала чаще всего

🔬 Результаты и выводы можно посмотреть внутри **real_cnc.ipynb**
